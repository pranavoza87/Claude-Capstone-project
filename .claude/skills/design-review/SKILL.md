# Design Review Skill

- Verify every requirement and edge case is covered by the proposed architecture and API/UI contracts.
- Flag SQLite migration risks, destructive schema changes, error handling gaps, and missing test coverage by severity.
- Pause at the HITL gate and present the design review findings for explicit approval before writing `docs/design-review.md`.
