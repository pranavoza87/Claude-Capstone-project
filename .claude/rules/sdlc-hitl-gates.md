# SDLC Human-in-the-Loop (HITL) Rules

- Never modify code, write/edit documentation artifacts, commit changes, push branches, or invoke external write MCP tools (GitHub MCP or Jira MCP) without explicit human approval at the corresponding HITL gate.
- Present concrete inputs, scope, target files/PRs/tickets, and test/review evidence before asking for approval.
- Keep unrelated existing code and out-of-scope files untouched unless explicitly requested.
